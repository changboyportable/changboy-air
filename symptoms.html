```
🔧 28 อาการเสียแอร์เคลื่อนที่ที่พบบ่อย

รวมอาการผิดปกติของแอร์เคลื่อนที่ที่ผู้ใช้งานพบได้บ่อย พร้อมแนวทางตรวจสอบเบื้องต้น เพื่อช่วยให้เข้าใจปัญหาก่อนตัดสินใจซ่อม

```
❄️

แอร์เคลื่อนที่ไม่เย็น

เปิดเครื่องแล้วมีลมออก แต่ห้องไม่เย็นหรือเย็นน้อยลง อาจเกี่ยวข้องกับระบบทำความเย็น ลมผ่านคอยล์ พัดลม เซนเซอร์ หรือระบบควบคุม

อ่านบทความ แอร์เคลื่อนที่ไม่เย็น →
🔌

แอร์เคลื่อนที่เปิดไม่ติด

กดเปิดแล้วเครื่องไม่ทำงานหรือไม่มีการตอบสนอง อาจเกี่ยวข้องกับไฟเลี้ยง ฟิวส์ แผงวงจร รีเลย์ สวิตช์ หรือระบบควบคุม

อ่านบทความ แอร์เปิดไม่ติด →
🌀

พัดลมไม่ทำงาน

เปิดเครื่องแล้วพัดลมไม่หมุนหรือลมไม่ออก อาจเกิดจากมอเตอร์ คาปาซิเตอร์ แผงวงจร หรือระบบไฟฟ้า

อ่านบทความ พัดลมแอร์ไม่ทำงาน →
⚙️

พัดลมมอเตอร์มีปัญหา

มอเตอร์พัดลมอาจหมุนผิดปกติ หมุนช้า มีเสียง หรือไม่หมุนเลย ควรตรวจสอบมอเตอร์ คาปาซิเตอร์ และระบบไฟเลี้ยง

อ่านบทความ พัดลมมอเตอร์ →
🐢

พัดลมหมุนช้า

พัดลมหมุนช้ากว่าปกติ ลมออกเบา หรือเครื่องทำความเย็นได้ไม่ดี อาจเกี่ยวข้องกับมอเตอร์ คาปาซิเตอร์ หรือสิ่งสกปรก

อ่านบทความ พัดลมแอร์หมุนช้า →
🌬️

ลมแอร์ออกเบา

ลมออกจากช่องแอร์น้อยกว่าปกติ อาจเกิดจากแผ่นกรองอากาศสกปรก พัดลมมีปัญหา หรือมีสิ่งกีดขวางทางลม

อ่านบทความ ลมแอร์ออกเบา →
🧯

คอมเพรสเซอร์ไม่ทำงาน

เครื่องเปิดติดและมีลม แต่คอมเพรสเซอร์ ไม่เริ่มทำงาน อาจเกิดจากคาปาซิเตอร์ รีเลย์ แผงวงจร ระบบป้องกัน หรือคอมเพรสเซอร์

อ่านบทความ คอมเพรสเซอร์ไม่ทำงาน →
❄️

คอมเพรสเซอร์ทำงานแต่ไม่เย็น

คอมเพรสเซอร์ทำงานแต่ความเย็นไม่เพียงพอ ควรตรวจสอบระบบทำความเย็น น้ำยา ลมผ่านคอยล์ และสภาพของเครื่อง

อ่านบทความ คอมเพรสเซอร์ทำงานแต่ไม่เย็น →
🌡️

คอมเพรสเซอร์ร้อนจัด

คอมเพรสเซอร์ทำงานร้อนผิดปกติหรือตัดการทำงาน อาจเกี่ยวข้องกับการระบายความร้อน พัดลม ระบบทำความเย็น หรือการทำงานของเครื่อง

อ่านบทความ คอมเพรสเซอร์ร้อน →
🛡️

โอเวอร์โหลดตัดการทำงาน

เมื่อคอมเพรสเซอร์ร้อนหรือทำงานผิดปกติ ระบบป้องกันอาจตัดการทำงานเพื่อป้องกันความเสียหาย ควรหาสาเหตุที่ทำให้เกิดความร้อนก่อนแก้ไข

อ่านบทความ ระบบโอเวอร์โหลดและคอมเพรสเซอร์ร้อน →
⚡

แอร์เคลื่อนที่กินไฟมาก

เครื่องใช้ไฟฟ้ามากกว่าปกติหรือค่าไฟเพิ่มขึ้น ควรตรวจสอบคอมเพรสเซอร์ พัดลม ระบบทำความเย็น และระบบไฟฟ้า

อ่านบทความ แอร์เคลื่อนที่กินไฟ →
🔊

แอร์เคลื่อนที่เสียงดัง

มีเสียงสั่น เสียงครืดคราด เสียงมอเตอร์ หรือเสียงผิดปกติ อาจเกิดจากพัดลม มอเตอร์ ลูกปืน ชิ้นส่วนหลวม หรือคอมเพรสเซอร์

อ่านบทความ แอร์เคลื่อนที่เสียงดัง →
🧊

น้ำแข็งเกาะคอยล์

มีน้ำแข็งเกาะบริเวณคอยล์เย็น อาจเกี่ยวข้องกับลมผ่านคอยล์ไม่เพียงพอ แผ่นกรองสกปรก พัดลม ระบบทำความเย็น หรือเซนเซอร์

อ่านบทความ น้ำแข็งเกาะคอยล์ →
💧

แอร์เคลื่อนที่น้ำหยด

มีน้ำหยดหรือน้ำรั่วออกจากตัวเครื่อง อาจเกิดจากระบบระบายน้ำ ถาดน้ำ ท่อน้ำทิ้ง ปั๊มน้ำในบางรุ่น หรือสิ่งสกปรกภายในเครื่อง

อ่านบทความ แอร์เคลื่อนที่น้ำหยด →
🚰

น้ำระบายออกไม่ดี

น้ำสะสมภายในเครื่องหรือระบายออกช้า ควรตรวจสอบท่อน้ำทิ้ง ช่องระบายน้ำ ถาดรองน้ำ และสิ่งอุดตัน

อ่านบทความ ท่อน้ำทิ้งแอร์เคลื่อนที่ →
💦

น้ำรั่วจากตัวเครื่อง

น้ำรั่วออกบริเวณด้านล่างหรือด้านข้างของเครื่อง อาจเกี่ยวข้องกับระบบระบายน้ำ ถาดน้ำ หรือท่อระบายน้ำ

อ่านบทความ น้ำรั่วจากแอร์เคลื่อนที่ →
🌡️

เซนเซอร์อุณหภูมิทำงานผิดปกติ

เครื่องวัดอุณหภูมิผิดเพี้ยน แอร์ไม่ตัด หรือตัดเร็วเกินไป อาจเกี่ยวข้องกับเซนเซอร์ อุณหภูมิหรือระบบควบคุม

อ่านบทความ เซนเซอร์อุณหภูมิ →
🔬

เทอร์มิสเตอร์มีปัญหา

เทอร์มิสเตอร์เป็นอุปกรณ์ตรวจจับอุณหภูมิ หากค่าผิดปกติอาจทำให้ระบบควบคุม การทำงานของแอร์คลาดเคลื่อน

อ่านบทความ Thermistor →
🔋

คาปาซิเตอร์เสีย

คาปาซิเตอร์มีหน้าที่ช่วยในการทำงานของมอเตอร์ และคอมเพรสเซอร์ หากเสื่อมอาจทำให้มอเตอร์ หมุนช้า มีเสียงฮัม หรือคอมเพรสเซอร์สตาร์ตไม่ได้

อ่านบทความ คาปาซิเตอร์ →
🔌

รีเลย์ทำงานผิดปกติ

รีเลย์ใช้ควบคุมการจ่ายไฟไปยังอุปกรณ์ต่าง ๆ หากหน้าสัมผัสมีปัญหาอาจทำให้คอมเพรสเซอร์ หรืออุปกรณ์บางส่วนไม่ทำงาน

อ่านบทความ รีเลย์แอร์เคลื่อนที่ →
💻

แผงวงจร PCB มีปัญหา

แผงวงจรเป็นส่วนควบคุมการทำงานของเครื่อง หากเกิดความผิดปกติอาจทำให้เครื่องเปิดไม่ติด สั่งงานผิดปกติ หรืออุปกรณ์บางส่วนไม่ทำงาน

อ่านบทความ PCB แอร์เคลื่อนที่ →
🧹

แผ่นกรองอากาศสกปรก

แผ่นกรองที่มีฝุ่นสะสมมากจะทำให้ลมผ่านได้น้อย เครื่องทำงานหนักขึ้น และอาจส่งผลต่อประสิทธิภาพ การทำความเย็น

อ่านบทความ วิธีทำความสะอาดแผ่นกรอง →
🧽

ไม่ได้ดูแลแผ่นกรองเป็นประจำ

หากใช้งานแอร์เคลื่อนที่เป็นประจำ ควรตรวจสอบและทำความสะอาดแผ่นกรอง อย่างสม่ำเสมอ เพื่อช่วยให้ลมผ่านได้ดี

อ่านบทความ การดูแลแผ่นกรอง →
🔥

ท่อระบายลมร้อนร้อนผิดปกติ

ท่อระบายลมร้อนมีอุณหภูมิสูงเป็นเรื่องที่พบได้ แต่หากระบายความร้อนไม่ดีหรือท่อมีปัญหา อาจส่งผลต่อประสิทธิภาพของเครื่อง

อ่านบทความ ท่อระบายลมร้อน →
📏

ติดตั้งท่อระบายลมไม่เหมาะสม

ท่อระบายลมร้อนที่ยาวเกินไป งอมาก หรือมีสิ่งกีดขวาง อาจทำให้ความร้อนระบายออก ได้ไม่ดีและทำให้เครื่องทำงานหนักขึ้น

อ่านบทความ การติดตั้งท่อระบายลมร้อน →
📍

วางแอร์เคลื่อนที่ผิดตำแหน่ง

การวางเครื่องชิดผนังเกินไปหรือวางในจุดที่ระบาย ความร้อนได้ไม่ดี อาจทำให้ประสิทธิภาพลดลง และเครื่องทำงานหนัก

อ่านบทความ การวางแอร์เคลื่อนที่ →
⚡

แอร์เคลื่อนที่ใช้ไฟฟ้าสูง

การใช้ไฟสูงอาจเกิดจากระยะเวลาการทำงาน สภาพห้อง อุณหภูมิภายนอก การตั้งอุณหภูมิ หรือความผิดปกติของระบบ

อ่านบทความ การใช้ไฟฟ้าของแอร์เคลื่อนที่ →
🌬️

ระบบลมทำงานผิดปกติ

หากลมออกไม่สม่ำเสมอ ลมอ่อน หรือพัดลมทำงาน ไม่เต็มประสิทธิภาพ ควรตรวจสอบแผ่นกรอง มอเตอร์พัดลม และทางเดินลม

อ่านบทความ ระบบพัดลมแอร์เคลื่อนที่ →
⚠️ หมายเหตุ
อาการเดียวกันอาจเกิดจากหลายสาเหตุ จึงไม่ควรสรุปว่าเป็นอะไหล่ชิ้นใดทันที ควรตรวจสอบระบบและหาสาเหตุก่อนซ่อม เพื่อให้แก้ไขปัญหาได้ตรงจุด
